# Learn JavaScript

My journey learning JavaScript from scratch.

## Lessons

- lesson1.js: Variables, conditions (if/else), and loops.
- functions.js: Functions, parameters, and return values.
- exercises.js: multiply, isEven, and greater exercises.
- arrays.js: Arrays, push/pop, length, and loops over arrays.
- arrays_exercises.js: Max number, sumArray function, and even numbers.
- objects.js: Objects, methods, this, and arrays of objects.
- dom/: DOM basics, events, buttons, and input.
- todo/: To-Do list with Enter key, task counter, and done state.
- guess-game/: Number guessing game. [Live demo](https://b5awi77.github.io/Learn_JavaScript/guess-game/)
- game-XO/: Tic-Tac-Toe (XO) game for two players. [Live demo](https://b5awi77.github.io/Learn_JavaScript/game-XO/)

More lessons coming soon.
